# Identidade visual - Cadastro de Colaboradores

Decisão aprovada em 22/09/2026.

Referências utilizadas:
- Projeto interno AutomindTermos, especialmente estrutura visual, busca global e tratamento de cards/formulários.
- Imagens oficiais fornecidas pelo responsável do projeto.
- Site institucional Automind: linguagem visual "Simple · Smart · Reliable" e posicionamento ligado a engenharia, automação e transformação digital.

Regras:
- Usar somente logos/assets oficiais fornecidos ou aprovados.
- Paleta predominante: magenta, vinho, roxo, preto/grafite, branco e cinzas claros.
- Interface interna deve ser limpa, corporativa e com alta legibilidade.
- Evitar aparência padrão Bootstrap/ASP.NET sem customização.
- A busca por chamado TOPdesk deve ser uma ação principal da home.
- Componentes de segurança/"somente leitura" devem permanecer visíveis enquanto as integrações de escrita não forem aprovadas.
