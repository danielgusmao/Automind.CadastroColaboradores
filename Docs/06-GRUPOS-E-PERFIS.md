# Grupos e perfis

## Regra principal
Dado cargo + departamento, consultar usuários ativos equivalentes e calcular a interseção dos grupos diretos.

- grupos presentes em todos -> sugeridos e pré-selecionados;
- grupos presentes em parte dos usuários -> exibidos como exceções, não pré-selecionados;
- grupos protegidos -> nunca pré-selecionados.

## Usuário de referência
Opcional. Permite visualizar os grupos de um colaborador específico e copiar de forma assistida, nunca cegamente.
