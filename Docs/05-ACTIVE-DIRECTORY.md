# Active Directory

## Fase 1 - permitido
- autenticar usuário/senha;
- verificar grupo `_informatica`;
- pesquisar usuários;
- pesquisar cargos/departamentos;
- pesquisar superior imediato;
- listar OUs;
- listar grupos;
- comparar associação de grupos;
- verificar disponibilidade de login/UPN/e-mail.

## Fase 1 - proibido
- criar usuário;
- alterar usuário;
- redefinir/definir senha;
- adicionar/remover grupo;
- alterar manager;
- mover/criar objeto em OU.

Qualquer uma dessas operações deve ser apresentada e aprovada antes de implementação.
