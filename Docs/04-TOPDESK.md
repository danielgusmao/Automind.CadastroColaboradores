# TOPdesk

Endpoint identificado:
`GET /tas/api/incidents/number/{numero}`

O chamado `CRIAÇÃO DE USUÁRIO` entrega o formulário principalmente no campo `request`.

Exemplo real utilizado para desenho: `I2609-0223`.

Na versão final, a API deve usar autenticação técnica apropriada (API Account/Application Token). O login do operador da aplicação e a credencial técnica do TOPdesk são responsabilidades distintas.
